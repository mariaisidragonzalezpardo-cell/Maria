# Semana 11 — Taller Integrador de Módulo 3 · PARCIAL 2

**Módulo 3: Recursividad, ordenación y búsqueda — Cierre**

---

## Objetivos de aprendizaje

- Integrar recursividad, ordenación y búsqueda en la resolución de un problema combinado.
- Demostrar dominio del Módulo 3 en la evaluación parcial.

---

## Contenidos de la semana

### Teoría (martes + miércoles)

1. Repaso integrador dirigido por preguntas guía:
   - Relación entre ordenación y búsqueda binaria (¿por qué la segunda depende de la primera?)
   - Cuándo elegir cada algoritmo de ordenación
   - Casos base y pila de llamadas en funciones recursivas
2. Ejercicios tipo examen (sin resolver el real): trazado de código, análisis de complejidad

### Laboratorio (miércoles Gr. A / viernes Gr. B)

1. Taller integrador: dado un conjunto desordenado, implementar una solución que:
   - Lo ordene con el algoritmo de tu elección
   - Permita búsquedas eficientes repetidas (binaria)
   - Incluya al menos una función recursiva auxiliar
2. **PARCIAL 2** (evaluación presencial, sin IA)
