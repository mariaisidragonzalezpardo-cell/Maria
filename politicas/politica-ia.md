# Política de Uso de Inteligencia Artificial Generativa — INF 222

**Estructura de Datos · Semestre 2026-2**

---

## Postura general

El uso de asistentes de IA generativa (GitHub Copilot, Claude, ChatGPT u otros) **está permitido en laboratorios, tareas y en el proyecto final**, bajo las condiciones descritas en este documento. **No está permitido en evaluaciones presenciales (parciales).**

La IA es tu par de programación, no tu reemplazo. El curso evalúa si entiendes estructuras de datos: puedes usar IA para aprender más rápido, pero debes poder explicar cada línea de código que entregues sin el apoyo de ningún asistente.

---

## Lo que SÍ puedes hacer con IA

| Uso permitido | Ejemplo |
|--------------|---------|
| Generar ejercicios adicionales de práctica | "Dame 5 ejercicios de pilas en Python" |
| Obtener explicaciones conceptuales alternativas | "Explícame la diferencia entre una lista circular y una circular con nodo cabeza" |
| Revisar errores de sintaxis | Pegar tu código y preguntar "¿hay algún error de sintaxis?" |
| Generar casos de prueba adicionales | "Dame 10 casos de prueba para mi función `busqueda_binaria()`" |
| Obtener trazados de ejecución paso a paso | "Traza la pila de llamadas de esta función recursiva" |
| Generar la estructura inicial (esqueleto) de una clase | Con declaración de uso obligatoria |

---

## Lo que NO puedes hacer con IA

| Uso prohibido | Por qué |
|--------------|---------|
| Pedirle a la IA que resuelva el laboratorio completo y subir eso sin modificaciones | No hay aprendizaje; viola la integridad académica |
| Entregar código generado por IA que no puedes explicar | En la sustentación quedará expuesto |
| Usar IA durante evaluaciones presenciales (parciales) | Está prohibido explícitamente |
| Copiar código de otro estudiante y usar IA para reescribirlo | Sigue siendo plagio |

---

## Declaración obligatoria de uso de IA

Cuando uses IA en cualquier entrega, debes agregar al archivo correspondiente (o al README del laboratorio) la siguiente sección:

```markdown
## Declaración de uso de IA

| Campo | Detalle |
|-------|---------|
| Herramienta usada | (ej. Claude 3.7, ChatGPT-4o, GitHub Copilot) |
| Para qué se usó | (ej. "para generar los casos de prueba" / "para explicarme la recursividad de factorial") |
| Qué hice yo | (ej. "implementé la lógica principal, solo usé la IA para revisar los edge cases") |
| Puedo explicar todo el código sin IA | Sí / No (si "No", revisa tu entrega antes de subir) |
```

Entregar sin esta sección cuando se usó IA equivale a **deshonestidad académica**.

---

## Actividad obligatoria con IA — Semana 8 (Recursividad)

En la semana 8, usarás un asistente de IA de forma guiada y obligatoria para obtener el trazado de una función recursiva. El requisito es que **reescribas el trazado con tus propias palabras y dibujes la pila de llamadas tú mismo**. Se evalúa tu comprensión, no el texto que generó la IA.

---

## Consecuencias de incumplimiento

El incumplimiento de esta política activa el procedimiento de integridad académica descrito en `reglas-del-aula.md`, que puede derivar en calificación de 0 en la entrega, apertura de expediente disciplinario, o ambas, según la gravedad.
